# Dragons of Mugloar — frontend

Vue 3 + TypeScript + Vite + Pinia single-page app. See the [root README](../README.md) for the full picture.

```bash
pnpm install
pnpm dev          # http://localhost:5173, proxies /api to the backend on :8080
pnpm test:unit    # Vitest
pnpm lint         # oxlint + ESLint
pnpm type-check   # vue-tsc
pnpm build        # production build into dist/
```
